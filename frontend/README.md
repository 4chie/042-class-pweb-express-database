# Manajemen Produk (React)

Halaman frontend sederhana untuk mengelola daftar produk (Tugas 3, Week 11), dibuat dengan React + Vite.
Data produk disimpan di state React (belum terhubung ke API).

## Fitur
- Menampilkan daftar produk dalam bentuk kartu (ID, nama, harga)
- Pencarian produk berdasarkan nama
- Pop-up Tambah Produk, Edit Produk, dan konfirmasi Hapus Produk
- Validasi form: nama wajib diisi, harga harus lebih dari 0

## Cara menjalankan
```bash
cd frontend
npm install
npm run dev
```
Buka alamat yang ditampilkan di terminal (biasanya http://localhost:5173).
